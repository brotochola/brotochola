## Featured work

### 🌱 Web Engine for Enhanced Dynamics — Multithreaded 2D Web Game Engine
A custom engine designed for high-performance browser games, built around worker-based architecture, SharedArrayBuffer-backed state, and browser-native rendering and physics pipelines.

- Live demo: https://multithreaded-game-engine.vercel.app/demos
- Repository: https://github.com/brotochola/Web-Engine-for-Enhanced-Dynamics
- Focus: high-entity simulation, spatial systems, Box2D/WASM, WebGPU, rendering architecture

### 🎹 modular_synth — Browser Modular Synthesizer
A modular synthesizer built directly in the browser with WebAudio and signal-routing tools for live experimentation and performance.

- Live synth: https://modular-web-synth-rosy.vercel.app/
- Repository: https://github.com/brotochola/modular_synth
- Focus: WebAudio, DSP, patching interfaces, modular design, interactive creative tooling

### ⚙️ Box2D 3.2 + LiquidFun Integration
A physics runtime and C/WASM integration project aimed at bringing real-time fluid and rigid-body simulation into browser-based game engines.

- Repository: https://github.com/brotochola/Box2d_3.2_C_-_liquidfun
- Focus: Box2D, LiquidFun, WASM, multithreaded physics, browser simulation
